Subversion permits multiple check-out, and in fact it doesn’t require you
to check out files explicitly at all. You simply start editing the files locally—
all files are writable on your local disk at all times. (By the way, this is one
reason that Subversion doesn’t scale well to large projects, in my opinion. To
determine which files you have changed, Subversion must search the entire
tree of source files, which can be slow. Version control systems like Perforce,
which explicitly keep track of which files you have modified, are usually easier
to work with when dealing with large amounts of code. But for small projects,
Subversion’s approach works just fine.)
