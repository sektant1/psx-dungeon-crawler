# 2.1.4 Setting up a Code Repository

<!-- source-pdf-page: 91 -->

The easiest way to get started with Subversion is to visit the website of He-
lixTeamHub or a similar SVN hosting service, and set up a Subversion repos-
itory. Create an account and you’re off to the races. Most hosting sites offer
easy-to-follow instructions.

Once you’ve created your repository, you can typically administer it on the
hosting service’s website. You can add and remove users, control options and
perform a wealth of advanced tasks. But all you really need to do next is set
up a Subversion client and start using your repository.
