# Raven Engine Media Kit

A complete grey/red, low-poly, late-1990s console-inspired identity package for Raven Engine.

## Included

- Cleaned transparent logos and monochrome variants
- Application icons and favicon/ICO sizes
- Front cover, back cover, full jewel-case wrap, disc label, and manual covers
- Posters, social banners, store capsules, wallpapers, and a physical-media mockup
- Palette files in PNG, JSON, CSS, and GIMP GPL formats
- Press copy, brand rules, asset manifest, source artwork, and contact-sheet previews

## Visual direction

Use severe black fields, cold grey metal, restrained red lighting, compact spacing, hard-edged panels, pixel-scale texture, and simple low-poly mecha silhouettes. Avoid glossy modern gradients, neon rainbow palettes, rounded consumer UI, and unrelated military insignia.

The package deliberately uses generic “32-bit / PSX-era inspired” packaging rather than production console trademarks.
