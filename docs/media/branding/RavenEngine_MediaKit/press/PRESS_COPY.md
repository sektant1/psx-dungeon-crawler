# Raven Engine — Press Copy

## One-line description

Raven Engine is an independent C++ engine project for compact low-poly worlds, editor-driven workflows, and severe late-1990s industrial presentation.

## Short description

Raven Engine combines a modular real-time runtime with a focused toolset for building low-poly 3D projects. Its visual identity is defined by cold gunmetal surfaces, restrained red optics, pixel-scale texture, and hard-edged mecha silhouettes.

## Boilerplate

Raven Engine is a technical portfolio and engine-development project focused on C++, real-time rendering, modular architecture, content tooling, and retro low-poly art direction. The project treats the late-1990s console era as a design constraint rather than a filter: geometry, texture density, lighting, interface composition, and presentation are developed as one coherent system.
