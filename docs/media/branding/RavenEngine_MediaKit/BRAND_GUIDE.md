# Raven Engine Brand Guide

## Core identity

**Name:** Raven Engine  
**Primary tagline:** Mech Combat. Total Control.  
**Secondary line:** Low-Poly Real-Time System.

## Palette

| Token | Hex | Use |
|---|---:|---|
| Void Black | #08080A | Main background |
| Carbon | #15171B | Panels and deep surfaces |
| Gunmetal | #2E333A | Frames and UI blocks |
| Steel | #666E79 | Secondary type and borders |
| Silver | #B7BDC5 | Primary wordmark and headings |
| Signal Red | #C1121F | Eye glow, rules, active state |
| Deep Red | #5A0E0E | Shadows and recessed accents |

## Typography

Recommended system substitutes:

- Display: Inter Display Black, all caps, tight leading
- UI/body: Inter Display Regular or Noto Sans
- Technical labels: DejaVu Sans Mono

Font files are not bundled. Use locally installed or licensed equivalents.

## Logo rules

- Keep clear space equal to the height of the `R` counter around the logo.
- Minimum digital width: 180 px for the stacked logo, 260 px for the horizontal wordmark.
- Prefer black or carbon backgrounds.
- Use red as an accent, not as the entire primary wordmark except for warning-state variants.
- Do not stretch, rotate, add outer glow, soften edges, or place over busy light imagery without a dark plate.

## Image treatment

- Reduce saturation slightly.
- Keep the image mostly black, graphite, and neutral grey.
- Use red only for optics, status lamps, rules, and shadows.
- Favor nearest-neighbor scaling, low-resolution texture, ordered noise, hard scanlines, and visible polygonal forms.
- Maintain high contrast around the silhouette and wordmark.

## Packaging

The cover files are aesthetic mockups, not console-certified packaging. Replace all placeholder copy, build identifiers, ratings, barcodes, legal text, and platform details before production.
